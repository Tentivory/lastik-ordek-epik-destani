# Lastik Ördek Epik Destanı

## Giriş

Bu repository, insanlık tarihinin en kritik krizini çözmek için yaratılmıştır: **Dev bir lastik ördeğin mahalleyi istila etmesi.**

Hayır, şaka değil. Gerçekten. Bilim adamları, filozoflar ve çaycılar yıllardır bu tehdidi görmezden geldi. Ama artık yeter!

Bu kod, rastgele epik Türk destanları üreterek lastik ördek tehlikesine karşı moral verir. Her çalıştırmada yeni bir kahraman doğar, yeni bir çay demlenir, yeni bir lastik ördek patlatılır.

## Kurulum

```bash
pip install -r requirements.txt  # aslında hiçbir şey yok ama olsun
python destan.py
```

## Nasıl Çalışır?

Kod, derin bir algoritma kullanarak (çay kaşığı kadar derin) rastgele kelimeleri bir araya getirir ve ortaya çıkan destanı size sunar. Her destan, lastik ördeğin yenilgisini garantiler. Garanti süresi: bir sonraki çay molasına kadar.

## Katkıda Bulunma

Pull request açmadan önce lütfen bir bardak çay için ve lastik ördeklerin ruhuna dua edin. Yoksa merge etmem.
